Automação de Arquivos com Python 🐍

📌 Sobre o projeto

Projeto desenvolvido durante meus estudos de Python, com o objetivo de aprender a trabalhar com diretórios e arquivos utilizando a biblioteca os.

A proposta é praticar operações básicas de navegação, consulta e verificação de arquivos e pastas, construindo a base para projetos futuros de automação.

📚 Conhecimentos praticados

os.getcwd(): consulta do diretório de trabalho atual.

os.listdir(): listagem de arquivos e pastas.

for: iteração sobre os elementos de uma lista.

len(): contagem de elementos.

os.path.exists(): verificação da existência de um caminho.

os.path.isfile(): identificação de arquivos.

os.path.isdir(): identificação de diretórios.

os.path.join(): combinação de caminhos e nomes de arquivos.
